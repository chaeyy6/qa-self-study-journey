# Zephyr Scale — Manual Testing Practice

## Overview

This project documents my hands-on practice using **Zephyr Scale** for test case management and manual test execution.

The project was completed as part of my QA self-study journey and was based on an instructor-provided practical testing project. The purpose was to gain experience with a professional test management tool and understand how test cases, folders, test cycles, executions, and test results are managed in a practical testing workflow.

## Project Objective

Practice using Zephyr Scale to:

- Create and organize test cases.
- Group test cases into folders and test suites.
- Create and manage test cycles.
- Execute test cases using the Test Player.
- Record test execution results.
- Track execution progress.
- Work with test case statuses and priorities.
- Understand how test management tools support manual testing workflows.

## Project Structure

The project was organized around multiple functional areas and testing scenarios.

Examples include:

- Login
  - Valid Login Scenarios
  - Invalid Login Scenarios
- Booking a Flight
  - Valid Selection Scenarios
  - Invalid Selection Scenarios
- Additional functional areas provided by the practice project.

## Zephyr Scale Features Practiced

### Test Case Management

Created and reviewed test cases containing information such as:

- Test Case ID
- Test Case Title
- Objective
- Preconditions
- Test Steps
- Expected Results
- Priority
- Status
- Folder
- Owner
- Labels

### Test Case Organization

Used Zephyr Scale folders to organize related test cases by functionality and scenario type.

Example:

text
Login
├── Valid Login Scenarios
└── Invalid Login Scenarios

This made the test suite easier to navigate and maintain.

### Test Cycles

Created and worked with a test cycle to group test cases for execution.

The test cycle provided an organized environment for:

- Selecting test cases for execution.
- Assigning testers.
- Tracking execution status.
- Recording execution results.
- Monitoring execution progress.
- Test Execution

Used the Zephyr Scale Test Player to execute assigned test cases.

During execution, I practiced:

- Reviewing test steps.
- Executing the required actions.
= Recording Pass/Fail results.
= Reviewing execution details.
= Tracking actual execution time.
- Reviewing test cycle progress.
- Execution Tracking

Used execution statuses to monitor testing progress, including:

- Passed
- Failed
- Blocked
- In Progress
- Not Executed
- Evidence
