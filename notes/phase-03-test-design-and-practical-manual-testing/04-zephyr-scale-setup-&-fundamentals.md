# Zephyr Scale — Setup & Fundamentals

## Objective

Understand the purpose of Zephyr Scale as a test management tool and how it provides a more structured approach to creating and organizing test cases compared with spreadsheet-based test management.

## 1. Zephyr Scale vs. Google Sheets

Google Sheets can be used to create and organize test cases, particularly for smaller projects or simple documentation.

Zephyr Scale provides functionality specifically designed for software test management, making it more convenient for organizing and managing test cases as testing activities grow.

### Google Sheets

Useful for:

- Simple test case documentation.
- Quickly creating and sharing test cases.
- Small projects and learning environments.

### Zephyr Scale

Provides a more structured approach to:

- Creating test cases.
- Organizing test cases.
- Managing test suites.
- Tracking testing activities.
- Managing test-related information within Jira.
