# Zephyr Scale — Setup & Fundamentals

## Objective

Understand the purpose of Zephyr Scale as a test management tool and how it provides a more structured approach to creating and organizing test cases compared with spreadsheet-based test management.

## 1. Zephyr Scale vs. Google Sheets

Google Sheets can be used to create and organize test cases, particularly for smaller projects or simple documentation.

Zephyr Scale provides functionality specifically designed for software test management, making it more convenient for organizing and managing test cases as testing activities grow.

### Google Sheets

Useful for:

- Simple test case documentation.
- Quickly creating and sharing test cases.
- Small projects and learning environments.

### Zephyr Scale

Provides a more structured approach to:

- Creating test cases.
- Organizing test cases.
- Managing test suites.
- Tracking testing activities.
- Managing test-related information within Jira.

## 2. Organizing Test Cases with Folders

Zephyr Scale allows test cases to be organized into folders based on application features or testing areas.

Example:

Login
├── Valid Scenarios
└── Invalid Scenarios

Other possible feature-based folders include:

Sign Up
Shopping Cart
Checkout
Payment


This provides a structured hierarchy for managing related test cases.

## 3. Creating Test Cases

Zephyr Scale provides a dedicated interface for creating and managing test cases.

Instead of manually maintaining spreadsheet rows and columns, test cases can be created using the test management tool's dedicated structure and fields.

This makes test cases easier to organize as the project grows.

## 4. Permissions

Zephyr Scale operates within the Jira project environment.

Permissions determine what users can access or modify and are important when multiple team members are working within the same testing project.

## 5. Basic Workflow

The initial Zephyr Scale workflow introduced in these lessons was:


Jira Account
     ↓
Add Zephyr Scale
     ↓
Create Test Cases
     ↓
Organize Test Cases into Folders


This establishes the foundation for managing test cases within Zephyr Scale.

## Key Takeaways

* Zephyr Scale is designed specifically for software test management.
* Google Sheets can be useful for simple test case documentation and smaller projects.
* Zephyr Scale provides a more structured approach to organizing test cases.
* Folders can be used to group test cases by feature or testing area.
* Test cases can be organized into structures such as valid and invalid scenario groups.
* Zephyr Scale operates within the Jira project environment and uses project permissions.
