# Phase 02 — Manual Testing

This phase focuses on the practical skills required of a Manual QA Engineer.

## Topics

- Requirements Analysis
- Design Review
- What is a Test Scenario
- Creating Your First Test Scenario
- Using Prompt Engineering to Generate Test Scenarios
- Reviewing Test Scenarios and Assigning Priority
- Tracking Test Scenarios Using Trello
- Executing Test Scenarios
- Defect Reporting
- Creating Your First Defect Report
- Using Prompt Engineering for Defect Reporting

## Goal

Develop the practical skills needed to analyze requirements, create and execute effective test scenarios, prioritize testing activities, report defects clearly, and communicate professionally throughout the manual testing process.
