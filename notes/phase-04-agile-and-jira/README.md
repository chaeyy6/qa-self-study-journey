# Phase 04 — Agile & Test Management

This phase focuses on understanding Agile methodologies, managing Agile project artifacts, using Jira for Scrum and Kanban workflows, integrating test management tools, and applying Agile testing practices throughout the software development lifecycle.

## Topics

- Creating Scrum Project in Jira
- Managing Agile Project Artifacts
- Choosing Test Management Tool for Test Case Writing
- Integrating Qase with Jira
- Creating Test Cases & Tracking Project Progress
- Agile Fundamentals
- Agile Team & Feedback
- Agile Requirements & User Stories
- Scrum & Agile Practices
- Kanban & Agile Testing
- Jira & Scrum Project Setup
- User Stories & Acceptance Criteria
- Sprint Planning & Monitoring
- Agile Testing in Jira
- Jira Kanban, Bug Tracking & Confluence
- Testing Reports

## Goal

Develop practical Agile testing and test management skills by working with Scrum and Kanban workflows, creating and managing Agile project artifacts, writing user stories and acceptance criteria, planning and monitoring sprints, integrating test management tools with Jira, tracking defects, and using testing reports to monitor project quality and progress.
